# Open product decisions

Canonical owner of the short unresolved-decision register. Exact context and
resolved contracts belong to the affected owner in the [product core](../product-spec.md).

## Current register

No unresolved product decision is recorded by this documentation review
(2026-09-05). This is not a statement that all validation or release work is
complete. Public Store post-certification checks remain separate
[release gates](../../packaging/store/SubmissionChecklist.md).

When a task finds conflicting intent or requires a new product decision, add a
short item linking the owner and explaining what requires the user's decision.
Do not invent a roadmap or turn missing test evidence into an open design choice.

## Closing a decision

After an explicit decision, update the exact owner and affected implementation/
user-facing documentation, then remove the resolved item. Git owns the history.
Cross-system decisions still have one owner for each exact rule.
